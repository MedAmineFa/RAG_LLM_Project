# RAG_LLM_Project

# Description

Ce projet permet d’importer un fichier PDF (ex. finance.pdf) + json et de l’analyser automatiquement en utilisant des modèles RAG (Retrieval-Augmented Generation) et LLM (Large Language Models) via LangChain.
Le résultat est affiché sur un frontend Node.js, connecté à FastAPI, pour visualiser les réponses générées.

# Fonctionnalités principales

Importation et traitement de fichiers PDF

Analyse et extraction de données avec RAG + LLM via LangChain

Affichage interactif des résultats sur le frontend Node.js

Backend FastAPI pour gérer les requêtes et la logique métier

# Technologies utilisées

Python

FastAPI

Node.js (Frontend)

LangChain pour LLM et RAG

LangGraph pour Orchestration
